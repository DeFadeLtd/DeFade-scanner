# Helping DeFade

DeFade's scanning engine is closed source, so this repository doesn't take code changes to the scanner. There are still three ways to make DeFade better, and the first one matters most.

1. **Report a verdict that looks wrong.** A token DeFade called safe that rugged, or one it flagged that was fine. Use the [wrong verdict form](../../issues/new?template=wrong_verdict.yml) and add the token address, the chain, what the scan showed and the evidence. Every report is traced back through the scan.
2. **Report a bug** on the website, the apps, the extension, the bot or the API, with the [bug report form](../../issues/new?template=bug_report.yml).
3. **Suggest a signal, a chain or a launchpad** with the [idea form](../../issues/new?template=feature_request.yml). An example token where it would have helped makes the case.

Pull requests that fix or improve the [documentation](docs) and the [examples](examples) are welcome.

For a security problem, follow [SECURITY.md](SECURITY.md) instead. For your account or plan, email info@defade.org.
